# M7+ 地震マップ

日本で起きたマグニチュード7以上の地震（599年〜2026年11月6日、268件）を、日本地図・都道府県ランキング・
都道府県別の「次のM7以上の見通し」で見るスマホ向けアプリ（PWA）です。

**アプリ: https://chestnut8811-star.github.io/m7-jishin-map/**

スマホで開いて「ホームに追加」を押すと、ホーム画面にアイコンが出て、電波がなくても見られます
（iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome の確認画面で「インストール」）。

## ご注意
「見通し」は、地震調査研究推進本部（地震本部）の長期評価の確率と過去の記録から読み取った目安で、地震の予知ではありません。
確率は2026年1月1日時点の値です。防災の判断は、気象庁・自治体の情報とハザードマップを確認してください。
